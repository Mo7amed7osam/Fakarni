How to create a reminder

Open Fakarni, tap the main microphone button, and speak the reminder naturally. If the title, day, or time needs a quick correction, the confirmation screen lets you adjust it before saving.

Notifications are not arriving

Fakarni uses local notifications for reminder delivery. If reminders are saved but not arriving, confirm that iPhone notifications are enabled for Fakarni in the device Settings app.

Voice capture is not working

Voice capture needs microphone and speech recognition access. These prompts should only appear when you start capture. If access was denied before, re-enable the permissions from the iPhone Settings app, then reopen Fakarni.

Calendar sync

Calendar save is optional. Fakarni asks for calendar access only when you enable calendar syncing. If access is denied, reminders still work inside the app and through local notifications.

Siri shortcuts and widget

On iPhone, Fakarni supports a home-screen microphone widget and Siri shortcuts to start voice capture faster. If those entry points open the app without starting recording, check microphone and speech recognition permissions first.
