What Fakarni does

Fakarni is a voice-first reminder app. Users can speak a reminder, review the parsed result, save it, receive local notifications, and optionally save reminders to a calendar provider when that feature is enabled.

Data stored on the device

Reminder titles, dates, times, completion state, recurrence details, and local app settings are primarily stored on the device so the app can function without an account system.

Permissions

Fakarni may request microphone access, speech recognition access, notification permission, and calendar access. These permissions are requested only when the related feature is used. The app should not request all permissions on first launch before user action.

Analytics

Fakarni can send anonymous product analytics to PostHog when analytics are enabled. According to the current app behavior, raw speech transcripts and reminder titles are not sent in analytics events. Users can disable anonymous analytics from the app settings.

Parsing gateway

If a production parsing gateway is configured, reminder text may be sent to that gateway to improve reminder interpretation. The mobile client does not ship provider secrets. If no gateway is configured, Fakarni falls back to local parsing and review mode instead of sending data to a model provider directly.

Calendar providers

Calendar writing is optional. When enabled, Fakarni may create calendar events with the reminder title and timing needed for the selected event. If calendar permission is denied, the app continues to work without calendar sync.

Notifications

Reminder delivery uses local notifications on the device. Notification scheduling and follow-up behavior are managed locally so reminders can arrive on time without requiring an always-on account backend.

User controls

Users can disable analytics in Fakarni settings. Users can also revoke microphone, speech, notification, or calendar permissions from iPhone Settings at any time. Removing the app also removes its locally stored data from the device.
